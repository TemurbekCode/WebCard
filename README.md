# WebCard

A personal digital business card that brings all my social media profiles and online presence together in one place.

## About

WebCard is a simple, modern, and responsive personal webpage designed to make connecting with me easier. It provides quick access to my social media profiles, contact channels, and personal website through a single page.

## Features

- Centralized links to social media and online profiles
- Quick access to contact channels
- Clean, responsive user interface
- Simple and convenient personal branding

## Built With

- React
- JavaScript
- CSS
- Vite

## Getting Started

Clone the repository and install the dependencies:

```bash
git clone https://github.com/TemurbekCode/WebCard.git
cd WebCard
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```
